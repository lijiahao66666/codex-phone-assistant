# Codex 手机助手 stable45 版本说明

记录日期：2026-11-09。面向 macOS Apple Silicon 助手和 H5。下载见[项目下载页](https://codex.air-inc.top/download/)和 [GitHub Releases](https://github.com/lijiahao66666/codex-phone-assistant/releases)。

## 本次修复

- 修复侧栏只观察前 4 条可见任务而漏掉运行转圈的问题。观察预算为 32，运行任务优先，其余候选轮转。
- 目录行增加运行状态汇总。折叠后，可信运行中的子任务仍使目录转圈；全部确认空闲后隐藏。状态未知时显示静态淡色虚线圈。
- 修复助手持有的空闲聊天释放、恢复后，同一 owner 的 revision 回退导致发送返回 409 的问题。保留原发送保护和未知结果不自动重发的行为。
- H5 不再请求未使用的 staged preview，避免部分连接重复传输预览和等价实时状态。聊天历史仍按需加载。

## 回归与实机结果

完整隔离回归 398/398 通过，失败、取消和跳过均为 0。新增覆盖隐藏子任务汇总、折叠观察、预算轮转、断线状态失效，以及真实 LocalOwner fixture 释放/恢复快照接入 connector 后的发送保护。模拟会话及模型不替代真实桌面验收。

本机已安装 stable45 助手，签名校验通过。专用 F 聊天先发送一条消息，再切走并折叠目录使其释放。恢复到同一 owner 后，第二条发送成功。两条用户请求在桌面原生记录中各出现一次，未再出现 revision-guard 拒绝。两次模型 final 各有两条不同 ID 的相同内容，原生记录本身也如此，不能据此判断为 H5 重复提交。

公网 H5 已核验 JS、CSS、HTML；本轮静态发布未重启中转服务、未改数据库。实测当前运行任务所在目录折叠后仍显示汇总转圈，动画处于运行状态，页面无横向溢出。全部空闲时隐藏的行为由隔离测试覆盖，尚未用一个专用真实目录采齐运行到完成的全过程。

长会话去除重复预览后的早期热连接探针，从约 1.62 秒降至约 0.40 秒，这是相近内容的两次样本。随后当前会话增长到约 71 万字符，切回两次仍分别约 7.70、7.73 秒。关联日志中助手就绪约 102 ms，编码约 110 ms。relay 首次写入约 649 ms；H5 首个 state 约 7.59 秒，处理约 32 ms。另一次公网下载 1 MiB 用时约 22.73 秒，说明当时传输也慢；尚未把网络、服务端至浏览器及并发影响完全分离，不能宣布长会话性能全部解决。

更多历史结果及覆盖范围见[阶段验收报告](stable41-acceptance-report-2026-11-09.md)与 [stable43 说明](stable43-release-notes-2026-11-09.md)。各版本样本分开记录。

## 保留限制

- 冷连接约 20–32 秒、跨端未读同步、桌面主动接管及助手持有写入权时归档、礼品卡旧恢复锁，按约定留到下一期。本版隐藏 H5 蓝点。
- 32 个观察预算已被运行任务占满时，其余子任务暂时保持未知；未知状态不表示运行或空闲。
- 超长单回合传输和长期多人负载仍需继续优化、验证；真实审批闭环、任务运行期间真正断线恢复仍未完成本版验收。
- 真实 iPhone 键盘、安全区、相机、两台真实电脑长期切换及 Windows 不包含在本轮 macOS 和浏览器模拟结果中。部分历史图片仅显示数量。
- Mac 包为 Apple Silicon、最低目标 macOS 12，使用临时签名，未公证，未用 macOS 12 真机验证。

本版发布已修复项，完整稳定版验收仍在进行。本项目不是 OpenAI 官方产品，桌面同步依赖非公开 IPC 协议。
