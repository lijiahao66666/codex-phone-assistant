# 附件入口本地改动

2026-11-06：输入框中的加号改为“添加附件”，点击后直接调用系统文件选择器，取消网页里的二次附件菜单。系统实际展示的相机、相册和文件入口仍由 iOS 决定。计划模式移到输入框下方，保留原有切换条件。

选中的 PNG、JPEG 和 WebP 显示缩略图，从文件入口选中的这些图片也按图片上传。PDF 显示第一页，视频显示一帧画面，文本和代码显示开头内容。其他文件显示类型、文件名和大小；无法解析的预览回退为文件卡片。附件仍可移除，并按聊天分别保存草稿。

视频限制为单个 10 MB（10 × 1024 × 1024 字节）。选择超过上限的视频时立即提示，不创建附件草稿，也不发起上传。其他附件沿用每个 20 MB、最多 4 个的限制。本次校验发生在 H5 选择文件时；服务端原有附件上限仍为 20 MB。视频只读取一帧用于本地缩略图，实际上传仍须用户点击发送。

预览在浏览器本地生成，不将文件提交给第三方转换服务。文本最多读取 8 KB，PDF 只渲染第一页，PDF 和视频最多同时处理 2 个。移除或发送成功时取消仍在运行的预览；生成失败后保留原始文件供发送。Word、Excel 和 PPT 没有接入转换，继续使用文件卡片。

PDF 使用固定版本 `pdfjs-dist@6.4.299`（Apache-2.0），按需加载压缩版解析器和 worker。预览模块未加载时不影响添加和发送附件。中转服务需在现有静态资源处理前接入 `src/transport/attachment-preview-assets.mjs` 中的 `serveAttachmentPreviewAsset(req, res)`；它只提供以下固定路径：

- `/attachment-preview.mjs`
- `/pdf-parser.mjs?v=6.4.299`
- `/pdf-worker.mjs?v=6.4.299`

H5 文档的 Content-Security-Policy 还需允许 `worker-src 'self'`，用于同源 PDF worker。库文件在安装 npm 依赖后从本机提供，不使用 CDN。解析器和 worker 带固定版本参数并支持 gzip；主预览模块不缓存。仓库内的 relay 历史快照没有修改，部署时需将上述处理器接入实际服务。

本地浏览器以 390 像素宽度完成验证。两页 PDF 显示第一页的红色画面，MP4 显示蓝色画面。文本中的 HTML 原样显示；DOCX 和损坏 PDF 保留文件卡片。切换聊天和移除附件没有混入其他聊天。10 MB 上限和超过上限 1 字节分别覆盖接受、拒绝；没有发起上传或发送请求。浏览器证据保存在工作区 `output/playwright/attachment-thumbnails-side-20261106.png`。

本次最终仓库测试共 74 项通过，其中包含工作区原有及同期新增的上传超时测试。附件相关新增测试覆盖本地预览、大小限制、固定资源路由及取消逻辑；JS 语法和 Git 空白检查通过。
