# Codex 手机助手 stable48 验收记录

记录日期：2026-11-10。范围为 macOS Apple Silicon 助手与 H5。构建号 50 在助手窗口增加检查更新和退出入口。

## 本版变化

- 异步问答按问题 ID 区分，减少重复题目展示；已确认答案与待确认写入分别处理，多题提交有串行和防重复保护。历史不完整且无法确认的问题仍保守处理。
- 支持新版 Codex 命令审批中的“允许一次”和“拒绝并中断”，不会把执行策略修订作为决定发送。
- Mac 助手接入 Sparkle 2 的签名更新检查。安装前会检查助手持有的任务及正在处理的操作。首个带此功能的版本需要手动安装；更新来源和私钥管理见 [macOS 更新说明](../macos/UPDATES.md)。
- 助手窗口提供“检查更新”和“退出助手”按钮，退出仍受任务保护约束。
- 保留大命令输出按需分页、任务运行指示和折叠目录汇总；H5 暂不显示未读蓝点。
- 目录汇总仅在折叠且确认有任务运行时显示；任务与聊天动画不受系统“减少动态效果”设置影响，H5 和桌面图标保持一致。

## 验收与边界

- 最终完整自动化回归 465/465 通过，日志 `/tmp/codex-stable48-final-full-tests.log`；包含真实隔离 CLI 审批链路，模型为模拟数据。
- 新版问答在真实 G 聊天中由 H5 提交，桌面问题框消失，原生记录收到一次答案并返回预期回复。桌面提交到 H5 的反向路径也有实测。多独立题、未确认写入和迟到响应由隔离测试覆盖。
- 真实 app-server、IPC、助手、relay 与 HTTP 审批链路在隔离目录中测试：允许一次后命令执行并完成，拒绝并中断后回合中断；模型响应为模拟数据。
- Sparkle 使用独立测试应用、测试密钥、回环 HTTP 和 stub runtime 实测：错误签名被拒绝；退出被阻止时旧应用未替换，解除阻止后升级重启成功；直接升级成功。生产签名源使用 HTTPS。测试不代表 Apple 公证或真实用户数据迁移验收。
- 专用聊天运行中关闭该聊天 SSE 后自动重连，任务继续执行，完成后转圈消失；恢复后发送一次并在桌面原生记录确认。未模拟整机离线或助手进程崩溃。
- 新版 H5 真实连续切换 40 次，选中无误，最终连接及模型、思考等级正确。长聊天切回样本约 0.54、0.65 秒；此前也观察到 6.40、8.87 秒，网络和长回合体积会影响耗时，不能保证始终在 2 秒内。模拟手机宽度验证了问答布局，不等同于真实 iPhone。
- 最终 stable48 助手和 H5 组合再次验证真实发送，原生记录中请求及预期回复各一条。长聊天两次切回约 3.90、2.39 秒，短聊天约 0.39 秒，均已连接且输入可用。
- 2026-11-10 只读核对当前列表有 56 个聊天，stable41 的 53 个目标均仍在，新增 3 个。最终组合另抽查项目内运行聊天和无项目聊天，均连接成功、输入可用，分别显示 Terra/high 和 Terra/xhigh；无项目控件隐藏。无项目聊天冷连接约 33.6 秒，属于延期的冷连接优化。记录 `/tmp/codex-stable48-sample-other-chats.json`。
- 两模拟电脑、多个任务和快速切换已有隔离负载与设备隔离测试；没有完成多台真实电脑长期并发验收。不同历史版本的实测不能一概视为本版全部功能重测通过。

## 已知限制

冷连接、长会话持续连接与进一步提速、跨端未读同步、桌面主动接管与助手持有写入权时归档、礼品卡旧恢复锁按约定留到下一期。部分历史图片只能显示数量。真实 iPhone 键盘、安全区和相机、Windows 以及多台真实电脑长期并发不在本轮实机覆盖内。

退出时会阻止进行中的转发及附件操作，并等待本机发送队列排空。队列排空不代表手机已收到回执，断线时结果仍可能未知。

Mac 安装包为 Apple Silicon，最低构建目标 macOS 12，使用 ad-hoc 签名且未公证。更新包的 EdDSA 验证不能替代 Apple 公证；本项目不是 OpenAI 官方产品，桌面同步依赖非公开 IPC 协议。
