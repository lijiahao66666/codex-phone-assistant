# 手机端与 Codex 能力对照

Codex 手机助手为电脑上的 Codex 提供远程界面。手机端只能使用桌面端已经暴露并实现的 IPC 和 HTTP 桥接能力；电脑版新增或未接入的功能不会自动出现在手机上。

## 当前支持

| 能力 | 手机端 | 说明 |
| --- | --- | --- |
| 电脑配对 | 支持 | 配对码、二维码、切换已配对电脑、移除配对 |
| 项目列表 | 只读与选择 | 查看已有项目；新聊天可选择项目，不能创建项目 |
| 任务列表 | 支持 | 实时更新进行中和最近任务；从项目或顶部创建聊天，暂不显示未读蓝点 |
| 任务历史 | 支持 | 最近内容先显示，更早内容按页读取；历史本身不授予控制权限 |
| 消息 | 支持 | 向选中的任务发送新消息；任务运行时作为补充输入 |
| 停止任务 | 支持 | 停止当前已知且由当前电脑持有的运行中任务 |
| 新建聊天 | 支持 | 首次发送时创建，先打开原生桌面聊天并确认桌面 owner，再发送首句；会切换桌面当前聊天，H5 无需关闭 |
| 历史聊天恢复 | 支持 | 无 owner 时先只读查看，自动核对归属并安全恢复；冲突或结果未知时拒绝写入 |
| 模型与推理强度 | 支持 | 使用电脑返回的可用列表，空闲时切换；结果未知时先确认状态 |
| 计划模式 | 支持切换 | 在 `Plan` 和 `Default` 之间切换；仅任务空闲且状态可确认时可用 |
| 目标信息 | 只读 | 显示目标状态、目标内容和计时；不能设置或控制目标 |
| 审批 | 部分支持 | 支持命令和文件变更审批；未知请求会提示回到电脑处理 |
| 问题回复 | 支持 | 支持待处理问答和异步问题 |
| 任务摘要 | 支持 | 查看子智能体活动、文件变更等摘要 |
| 附件 | 条件支持 | 最多 4 个文件或图片，每个不超过 20 MiB；视频选择上限 10 MiB；需要桌面端启用上传能力 |
| 语音输入 | 浏览器支持时可用 | 使用手机浏览器的语音识别，不是 Codex 原生语音功能 |
| 图片/文件预览 | 条件支持 | 受桌面端媒体能力、文件范围和平台开关限制 |

## 当前未实现

| 能力 | 状态 | 当前限制 |
| --- | --- | --- |
| 目标模式 | 未实现选择 | 只能显示已有目标，不能创建、修改、暂停、恢复或清除目标 |
| 插件选择 | 未实现 | 不能查看或选择任务使用的插件 |
| 应用/连接器选择 | 未实现 | 不能选择 Apps、MCP 或连接器 |
| 计划/默认以外的模式 | 未实现 | 仅桥接 `plan` 和 `default` |
| 项目创建与管理 | 未实现 | 不能新建、重命名、移动、置顶或删除项目 |
| 任务管理 | 部分支持 | 归档和删除经电脑端执行；不能重命名、置顶或移动任务 |
| 工作目录/分支/工作树 | 未实现 | 不能为任务选择 cwd、Git 分支或 worktree |
| 环境选择 | 未实现 | 不能切换本地、远程或其他执行环境 |
| Windows 图片/文件上传 | 默认未启用 | Windows 包默认关闭媒体能力；需要显式设置 `HUB_IMAGE_UPLOAD=1`，文字消息不受影响 |

## 术语区分

- **计划模式**：`Plan`/`Default` 协作模式。手机端有切换入口，但要求任务空闲且桌面端状态可验证。
- **目标模式**：Codex 的持久目标信息。手机端只显示已有目标，不能选择或管理目标模式。
- **应用/插件**：电脑版中的 Apps、连接器或插件配置。手机端没有对应选择器，发送消息时也不会替用户修改这些设置。

## 实现边界

- 手机端写操作都会重新确认任务 owner，拒绝把旧状态用于写入。
- 无 owner 的历史先只读显示；自动核对并恢复后由手机助手持有。电脑已有 owner 时沿用该 owner，归属变化或结果未知时停止后续写入。
- 新建聊天的即时桌面交接不适用于历史恢复会话。恢复会话须满足空闲和无待处理操作等条件才释放手机 writer；仍有手机页面查看时不会因任务列表订阅变化而释放。
- 历史分页、媒体预览和附件上传受协议版本及桌面端能力开关约束。
- 桌面端无法识别的新请求会要求回到电脑处理，而不是猜测或尝试其他 IPC 方法。

Windows 使用相同 runtime；新建聊天、恢复和模型切换仍缺第二台真实 Windows 电脑的完整实机验收。
