# Windows 0.3.50 版本说明

记录日期：2026-11-10。版本 `0.3.50`（构建号 50），面向 Windows 10/11 x64。

## 本版修复

- 安装器在写入文件前检查助手是否仍在运行。
- 新版本支持通过本地命名事件 `Local\codex-phone-assistant-quit` 请求助手正常退出。
- 安装器会先请求已运行的 0.3.50+ 助手退出，等待后再次检查窗口；未退出时明确提示从托盘退出，不再覆盖到一半才报告 DLL 被占用。
- 卸载器也会在助手运行时阻止卸载，避免留下部分程序文件。
- 保留 0.3.49 的签名更新清单、SHA-256 校验、静默安装和重启流程。

## SmartScreen

安装器没有 Authenticode 商业证书签名，Windows SmartScreen 可能提示未知发布者。这是发布者信誉提示，不是更新清单或安装包摘要校验失败。应先核对页面提供的 SHA-256，再对本次确认过的文件选择“更多信息” → “仍要运行”。

不应通过安装自签名根证书、关闭 SmartScreen 或添加全局 Defender 排除项来规避警告。

## 验证要求

- 更新清单必须使用固定的 ECDSA 公钥验证。
- 完整安装包必须匹配清单中的字节数与 SHA-256。
- 运行中的旧版必须保留原安装目录，直到安装器确认可以安全退出。
- 构建过程必须通过更新服务和更新助手自测。
- 正式发布后需在本机执行一次“运行中重新安装 → 退出提示 → 正常安装 → 启动”验证。
