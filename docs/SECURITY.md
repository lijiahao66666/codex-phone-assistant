# 安全说明

## 本地权限

- Codex 会话和任务索引只从当前用户的 `~/.codex` 读取。
- Windows 配对凭据位于 `%USERPROFILE%\.config\codex-hub\host.json`，创建后使用 `icacls` 限制为当前用户。
- macOS/Linux 使用 `0700` 目录和 `0600` 文件权限。
- 配对凭据、日志、真实会话和安装产物不得提交到 Git。

## 网络边界

- 云端连接只允许配置的 HTTPS origin 和对应 WSS `/connector` 路径。
- 本机配对面板只绑定 `127.0.0.1`。
- 请求必须匹配 loopback Host 与 Origin；管理 API 还要求同源请求和私有 Cookie。
- 手机端不能通过该服务访问任意 URL 或本地文件。

## 数据

- 默认会读取任务标题、状态、消息历史和允许预览的媒体引用。
- Windows 构建默认关闭图片上传与媒体预览。
- 预览句柄绑定主机、设备、任务和文件身份，并设置过期时间。

## 发布前检查

- 确定项目许可证和第三方依赖分发义务。
- 确认应用图标、OpenAI 图形标志及服务域名的使用权限。
- 对准确认线上中转和 H5 的版本、认证、日志保留及备份策略。
- 执行秘密扫描、个人信息检查和安装包代码签名。
