# Codex 手机助手 stable46 版本说明

记录日期：2026-11-09。面向 macOS Apple Silicon 助手和 H5。下载见[项目下载页](https://codex.air-inc.top/download/)及 [GitHub Releases](https://github.com/lijiahao66666/codex-phone-assistant/releases)。

## 长会话的大输出分批读取

此前实时首包保留最近 3 个回合，但每个回合可能包含很多命令和输出。一个命令输出就可能超过 300 KB，折叠显示也不能减少传输。

新版将超过 4 KiB 的命令输出改为按需读取。聊天先接收消息、命令摘要和运行状态。用户展开命令后加载输出，每页最多 16,384 个 JavaScript 字符，可以继续读取。单条输出的显示缓存最多保留 2 Mi 字符。达到上限后换到下一部分，仍可逐页访问全部输出，也可以从头查看。

运行中输出更新后，页面提示重新加载，避免旧页混入新结果。切换任务或电脑时，旧请求迟到也不能写入当前页面。服务器每页检查当前输出 hash；浏览器累计检查字节总数，完整保留的输出还校验 SHA-256。超过显示缓存、分窗读取的输出不在浏览器执行完整文本 SHA-256 校验。

本次分页覆盖工具输出。首份聊天状态仍要收齐一份 JSON；用户消息、模型回复、审批及命令摘要保持原样。旧助手或未协商此能力的页面继续使用完整输出，身份不唯一的命令也保留完整内容。

## 已完成的验证

- 最终完整隔离回归 417/417 通过，失败、取消、跳过均为 0。覆盖协议、设备隔离、未知写入、历史、按需输出、Unicode 分页、输出变化和迟到响应等。模拟模型不替代真实桌面操作。
- 公网 H5 与本机助手已部署。发布先启用 relay 新接口，再更新页面，配对数据库未修改。发布脚本的正常部署、显式回滚和重启失败自动回滚均做了隔离演练。
- 同一实际长聊天的相邻探针，完整首包为 1,087,648 B，按需版为 331,884 B，约减少 69.5%。当时两次耗时分别约 5.42、5.38 秒，不能把体积减少说成同幅度提速。
- 随后的真实切换中，长聊天切回分别约 10.06、2.38 秒，连接后模型和推理强度正确、输入可用。另一次热重连约 1.32 秒。长会话耗时仍有波动，尚未宣布性能全部解决。
- 真实展开一条 10,509 B 输出已完整加载；另一条 326,909 B 输出点击继续加载后，前端保留了前 32,768 字符，分页游标同步推进。大输出分页的完整性和切换隔离有自动化覆盖，全部输出类型及所有手机浏览器仍未实测。

前一版修复的任务转圈、折叠目录汇总和恢复后发送 409 保留，详细实测见 [stable45 说明](stable45-release-notes-2026-11-09.md)。更早功能与限制见[阶段验收报告](stable41-acceptance-report-2026-11-09.md)。

## 保留限制与覆盖范围

冷连接约 20–32 秒、跨端未读同步、桌面主动接管与助手持有写入权时归档，以及礼品卡旧恢复锁按约定留到下一期。H5 本版隐藏未读蓝点。32 个侧栏观察预算被运行任务占满后，其他任务暂时显示状态未知。

公网传输速度和超长单回合仍影响切回耗时。长期多人负载、真实审批闭环、任务运行中真正断线恢复尚未完成本版验收。真实 iPhone 键盘、安全区、相机、两台真实电脑长期切换及 Windows 不在本轮 macOS 与浏览器模拟结果内。部分历史图片仅显示数量。

Mac 安装包为 Apple Silicon，最低构建目标 macOS 12，临时签名且未公证，未用 macOS 12 真机验证。本项目不是 OpenAI 官方产品，桌面同步依赖非公开 IPC 协议。
