# Codex 手机助手 stable43 版本说明

记录日期：2026-11-09。本版面向 macOS 助手与 H5，支持在手机查看和操作已配对电脑上的 Codex 聊天。下载入口见 [下载页](https://codex.air-inc.top/download/) 和 [GitHub Releases](https://github.com/lijiahao66666/codex-phone-assistant/releases)。

## 本版变化

- 冷连接期间可先显示有界的只读历史；实时连接建立前不会把预览当作实时状态。
- 设备业务请求绑定当前配对，切换电脑时隔离旧连接、草稿及未确认操作；侧栏状态流也校验设备。
- 修复运行中追加消息、连续纯图片以及相同文字的不同消息可能被覆盖或误删的问题。
- 历史与实时内容按消息身份合并，保留已知顺序，避免同一消息重复或回合错序。
- H5 暂时隐藏未读蓝点，待跨端已读同步完善后恢复。

## 验证结果与范围

- 完整隔离自动化回归 389/389 通过；包括协议、设备隔离、历史、消息和上传等测试。CLI 集成使用模拟模型，不能替代所有真实桌面场景。
- stable41 对 53 个目标聊天中的 52 个可测聊天分轮检查，均连接成功且输入可用；礼品卡聊天因旧恢复锁按约定跳过。测试期间曾因浏览器交接中断，随后在同一版本续测，不是一次连续运行。
- stable43 在专用聊天实测了消息追加与历史顺序；stable42 实测了相同文字和两次纯图片均保留。空闲聊天在助手断开后，同页恢复了连接、模型和输入框。
- stable40 的专用聊天快速切换、附件与后台运行状态已有通过样本；它们不能自动代表 stable43 的全部场景都已复测。
- 两个模拟电脑及配对设备的本地 HTTP/WebSocket 隔离探针 24/24 通过；尚未用两台真实电脑完成多标签切换验收，也不据此保证所有安全场景。
- 一次实际长聊天停留几分钟后切换样本，记录的三个切换耗时分别为 2.98、0.76、2.28 秒；这是单次样本，不代表所有长会话或长时间驻留结果。
- 另一次主聊天驻留约 8 分 38 秒，页面字符数从 478,896 增至 497,813；切到另一聊天耗时 608 毫秒，切回主聊天耗时 2,007 毫秒，随后显示已连接、输入可用且任务运行中。这是单次样本，不能证明长期持续接收大量消息后的全部表现。
- 本地隔离负载样本中，5 个模拟电脑、各 4 个任务共完成 200 次切换和 40 次列表请求，约 26 秒全部通过；模拟结果不能推断真实多人长期容量。

更详细的版本、操作和证据边界见 [验收报告](stable41-acceptance-report-2026-11-09.md)。报告中的测试结果按各自实际版本和样本记录，不能合并成最终版本全场景通过。

## 已知限制

- 部分聊天冷连接实测约需 20–32 秒；首屏只读历史可以更早出现。实时连接速度优化留到下一期。
- H5 已读无法可靠同步清除桌面未读状态；本版隐藏 H5 蓝点，跨端同步留到下一期。
- 助手持有写入权时，桌面主动接管和归档有限制；礼品卡聊天旧恢复锁仍保留，均留到下一期。
- 部分历史图片仅显示数量，暂不支持预览。
- 多人、多任务长时间运行及大量消息后的切换负载尚未充分验证；真实审批闭环、任务运行期间断线恢复也未完成验收。真实 iPhone 键盘、安全区、相机及 Windows 新能力不包含在本轮 macOS 与浏览器模拟结果中。

本项目不是 OpenAI 官方产品；桌面同步依赖可能随 Codex 更新变化的非公开 IPC 协议。
