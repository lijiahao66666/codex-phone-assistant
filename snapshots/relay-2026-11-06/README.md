# Relay 源码快照

`pair-relay.mjs` 来自本地 `tools/codex-hub/releases/2026-11-06/` 发布快照。原始记录指出它需要对应版本的其他模块、静态资源与部署配置；本目录不构成可运行的部署包。

本分支已将配对注册表导入改为仓库中的 `src/pairing/registry.mjs`，并补充无损 gzip 上传分片解析。静态资源仍使用原来的 `./public/` 相对位置，未提供完整启动和部署配置，不能直接从本目录启动服务。

真实 HTTP、WebSocket 连接器和 UploadStore 测试覆盖压缩与原始分片混合上传，解压后的文件字节一致。解析器将压缩输入和解压输出分别限制为 128 KB，拒绝损坏数据、解压超限和不支持的编码。线上发布使用了经过哈希核对的增量补丁，详见 `docs/h5-validation-2026-11-06.md`。
